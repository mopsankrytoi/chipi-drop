# Чипи Дроп

Первая демонстрационная версия Telegram Mini App / адаптивного веб-приложения.

## Что есть в прототипе
- Главная страница в тёмно-изумрудном стиле.
- Бесплатные демонстрационные открытия коллекций.
- Коллекция найденных декоративных предметов.
- Профиль.
- Адаптивная вёрстка для телефона и компьютера.

Все предметы в этой версии являются виртуальными демонстрационными объектами. Здесь нет оплаты, ставок, вывода денег или обещания реальных подарков. Содержимое коллекции пока хранится только в памяти страницы и сбрасывается после перезагрузки.

## Публикация на Render
Создайте Static Site и подключите GitHub-репозиторий.

- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

После публикации Render выдаст публичный HTTPS-адрес сайта.

## Запуск локально (необязательно)
```bash
npm install
npm run dev
```
